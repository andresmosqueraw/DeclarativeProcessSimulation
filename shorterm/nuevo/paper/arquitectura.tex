  \caption{Detailed architecture of the \texttt{nuevo} pipeline. 
           \textbf{Phase 1} (left): \texttt{extract\_bpmn\_json.py} compresses the event log, 
           creates Simod configuration, executes Simod via Docker for BPMN discovery and parameter 
           estimation, then copies results to \texttt{data/generado-simod/}. 
           \textbf{Phase 2A} (center): \texttt{compute\_state.py} loads configuration and files, 
           reads the event log, calculates cut-off points using strategies (fixed, wip3, or segment10), 
           then for each cut point: preprocesses the log, computes partial process state (identifying 
           ongoing activities, building N-gram indices, computing control-flow markings), and saves 
           multiple state files to \texttt{data/generado-state/}. 
           \textbf{Phase 2B} (right): \texttt{run\_simulation.py} finds all state files, iterates over 
           each one, executes short-term simulation via Prosimos using each partial state as initial 
           condition, and organizes outputs in folders \texttt{punto-corte-1/}, \texttt{punto-corte-2/}, 
           etc. within \texttt{data/generado-short-term-simulation/}.}
